# 四维度检查清单

评分口径：结构 30 分、布局 25 分、可访问性 25 分、代码规范 20 分，合计 100。

## 一、结构（30 分）

| 项 | 通过标准 | 扣分 |
| --- | --- | --- |
| 文档声明 | 首行 `<!DOCTYPE html>` | 缺则 −5 |
| 语言声明 | `<html lang="zh-CN">` | 缺则 −3 |
| 语义标签 | 头部 `header`、导航 `nav`、主体 `main`、页脚 `footer` 至少各出现一次 | 每缺一个 −3 |
| 标题层级 | 只有一个 `h1`，且 `h2/h3` 不跳级 | 跳级 −3 / 多个 h1 −3 |
| 区域划分 | 用 `section` 或 `article` 承载内容块，而非满屏 `div` | 通篇只有 div −4 |
| 标题文案 | `<title>` 存在且 10～60 字符 | 缺失 −3 / 过长 −2 |

## 二、布局（25 分）

| 项 | 通过标准 | 扣分 |
| --- | --- | --- |
| 响应式基础 | 有 `meta viewport`，`width=device-width, initial-scale=1` | 缺则 −8 |
| 断点 | 至少一个 `@media` 适配窄屏（常见 640 / 768 / 1024） | 无 −5 |
| 布局方式 | 用 flex 或 grid 组织主干，而非浮动或绝对定位堆版 | 强行 float 布局 −4 |
| 盒模型 | 统一 `box-sizing: border-box`，无魔法数字（如 `margin-left: 273px`） | 出现 −3 |
| 溢出 | 长文本有换行或截断策略，窄屏无横向滚动条 | 有横向滚动 −3 |
| 图片 | `max-width: 100%` + 高度自适应，不变形 | 变形 −2 |

## 三、可访问性（25 分）

| 项 | 通过标准 | 扣分 |
| --- | --- | --- |
| 图片替代文本 | 每个 `img` 有 `alt`；纯装饰图用 `alt=""` | 每缺一个 −4 |
| 对比度 | 正文文字与背景对比度 ≥ 4.5:1；大字标题 ≥ 3:1 | 不达标 −5 |
| 可聚焦控件 | 链接与按钮能用 Tab 访问，`:focus-visible` 有可见轮廓 | 去掉 outline 且无替代 −4 |
| 表单 | 每个输入有 `label`（`for` 关联）或 `aria-label` | 每缺一个 −3 |
| 键盘语义 | 可点击的 div 改用 `button`/`a` | 用 div 冒充按钮 −3 |
| 文字缩放 | 正文不小于 16px，不用 `px` 锁死缩放后不可读的布局 | 正文 < 14px −2 |

## 四、代码规范（20 分）

| 项 | 通过标准 | 扣分 |
| --- | --- | --- |
| 样式外置 | 无 `style="..."` 内联样式（动态计算的除外） | 每处 −1，上限 −6 |
| 命名 | class 用语义化短横线命名，不出现 `div1`、`box2` | 每处 −1，上限 −4 |
| 缩进 | 同一文件缩进一致（2 或 4 空格） | 混用 −3 |
| 重复 | 同段 CSS 不在文件里出现两遍以上 | −3 |
| 注释 | 大区块有分节注释（非必需，加分项） | 不做扣分，做了 +2 上限 |
| 资源 | 无失效外链、无 404 的图片路径 | 每处 −2 |

## 硬性问题清单（不参与加分，出现即必修）

- 缺 `<!DOCTYPE html>`
- 缺 `meta viewport`
- `img` 无 `alt`
- 重复 `id`
- 标签未闭合或错配
- `html` 缺 `lang`

## 报告排序原则

1. 必修项按"会被直接扣分"排最前，每条带行号与替换代码。
2. 建议项按影响面排序（影响所有页面 > 影响单页 > 只影响维护）。
3. 最后单独列"做得好的地方"，至少两条，避免只输出负面清单。
